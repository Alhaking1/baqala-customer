# منظومة دُكّانك وبقالة الذكية المتكاملة 🏪📱
> **برمجة وتطوير: مجيب العباب**  
> الإصدار الرسمي: **v1.0.0 (Release)**

مستودع التحميل المباشر للنسخ الرسمية والنهائية (APK) لمنظومة إدارة البقالة الذكية ونقاط البيع وتطبيق الزبائن.

---

## 📦 التطبيقات المتوفرة للتحميل المباشر:

### 1. تطبيق التاجر - دُكّانك POS (`app-release.apk`)
- **الوصف**: تطبيق إدارة البقالة ونقاط البيع السحابية المتقدمة للتاجر والكواشير.
- **الحجم**: ~12.3 ميجابايت.
- **أبرز المميزات**:
  - إدارة المبيعات والفواتير السريعة والباركود والوزن.
  - دفتر حسابات وديون العملاء وكشوف الحسابات المعتمدة (PDF).
  - إدارة المخزون وتنبيهات الصلاحية والعروض الخاطفة.
  - منظومة الترخيص المركزي وإدارة الأجهزة وربط الكواشير.
  - مزامنة سحابية لحظية وتلقائية وتشفير محلي متكامل.
- **ملف التحميل**: [تحميل app-release.apk](https://github.com/Alhaking1/baqala-customer/raw/main/app-release.apk)

---

### 2. تطبيق الزبون - بقالة (`customer-release.apk`)
- **الوصف**: تطبيق خدمة العملاء والزبائن المرتبط مباشرة ببقالة التاجر.
- **الحجم**: ~21.2 ميجابايت.
- **أبرز المميزات**:
  - متابعة دفتر الحساب والديون والمسحوبات لحظة بلحظة.
  - طلب البضائع والتوصيل للمنازل مع تتبع حالة الطلب بالصوت والاشعارات.
  - متجر كروت شبكات الواي فاي وشراء الكروت مباشرة على الحساب.
  - حماية وأمان عالي بكلمة مرور مخصصة ومزامنة مشفرة.
- **ملف التحميل**: [تحميل customer-release.apk](https://github.com/Alhaking1/baqala-customer/raw/main/customer-release.apk)
