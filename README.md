# منظومة دُكّانك ( بقالتك ) الذكية المتكاملة 🏪📱
> **برمجة وتطوير: مجيب العباب**  
> الإصدار الرسمي: **v1.0.0 (Release)**

مستودع التحميل المباشر للنسخ الرسمية والنهائية (APK) لمنظومة إدارة البقالة الذكية ونقاط البيع وتطبيق الزبائن.

---

## 📦 التطبيقات المتوفرة للتحميل المباشر:

### 1. تطبيق التاجر - دُكّانك POS (`app-release.apk`)
- **الوصف**: تطبيق إدارة البقالة ونقاط البيع السحابية المتقدمة للتاجر والكواشير.
- **الإصدار**: 1.0.0 (Release)
- **أبرز المميزات**:
  - الفرز الصوتي الذكي للديون بمطابقة الاسم الأول وتفاصيل الصنف مع كشف المتشابهات آلياً.
  - إمكانية تعديل اسم الصنف والبيان والسعر عند الربط بحساب الزبون وحفظه في الفاتورة.
  - إدارة واعتماد طلبات الحسابات الآجلة المقدمة ذاتياً من الزبائن الجدد.
  - إدارة المبيعات والفواتير السريعة والباركود والوزن.
  - دفتر حسابات وديون العملاء وكشوف الحسابات المعتمدة (PDF) مع شارات تنبيه للديون المعلقة للفرز.
  - إدارة كروت وشبكات الواي فاي مع حفظ أسماء الشبكات في قائمة منسدلة وسقف الشراء المخصص.
  - إدارة المخزون والمزامنة السحابية اللحظية والترخيص المركزي.
- **ملف التحميل المباشر**: [تحميل app-release.apk](https://github.com/Alhaking1/baqala-customer/raw/main/app-release.apk)

---

### 2. تطبيق الزبون - بقالة (`customer-release.apk`)
- **الوصف**: تطبيق خدمة العملاء والزبائن المرتبط مباشرة ببقالة التاجر.
- **الإصدار**: 1.0.0 (Release)
- **أبرز المميزات**:
  - التسجيل الذاتي للزبون والبحث الفوري عن البقالة باسم المتجر، أو اسم صاحب البقالة، أو رقم هاتفه.
  - طلب فتح حساب آجل للتاجر مع إشعار بالقبول أو الرفض وإمكانية إعادة التقديم.
  - متابعة دفتر الحساب والديون والمسحوبات لحظة بلحظة.
  - طلب البضائع والتوصيل للمنازل مع تتبع حالة الطلب بالصوت والإشعارات.
  - متجر كروت شبكات الواي فاي المخصصة وفق صلاحيات وسقف كل زبون.
  - حماية وأمان عالي بكلمة مرور مخصصة ومزامنة مشفرة.
- **ملف التحميل المباشر**: [تحميل customer-release.apk](https://github.com/Alhaking1/baqala-customer/raw/main/customer-release.apk)
